# IPJIMAYO Firmware

ESP32-S3 (LOLIN S3 Pro) firmware for the IPJIMAYO smart clothing condition diagnosis system.

## Main Firmware

- `IPJIMAYO_ESP32_Firmware.ino`

## Features

- Bosch BME690 VOC sensing
- Bosch BSEC odor classification
- HP-501 heating profile
- BAD / NOT_BAD classification
- Capacitive moisture sensing
- 4010 FAN control
- Bluetooth Low Energy communication
- Direct diagnosis mode
- Automatic monitoring mode
